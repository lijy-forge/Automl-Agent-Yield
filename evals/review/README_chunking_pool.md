# YieldMind 分块 A/B 池化盲审

两套分块的 Top-K 候选已按文本合并去重，系统身份和原始排名已隐藏。两位评审独立完成各自 CSV，不要互相参考。

只编辑 `relevance`、`confidence` 和 `notes`：

- `2`：候选文本直接回答问题，可单独作为主要引用。
- `1`：提供相关背景或部分答案，但不足以单独支撑完整结论。
- `0`：无关、答非所问，或可能误导回答。
- `confidence`：`high`、`medium` 或 `low`。
- `notes`：可留空；边界模糊、问题有歧义或需多片段组合时请说明。

不要修改其他列，不要查看私有 manifest。CSV 使用 UTF-8 BOM。
